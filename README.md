# 《雨爱》· 钢笔淡彩手绘 MV

用**代码**画出来的 4 分 20 秒动画短片：1920×1080 / 16:9 / 24 fps，画面由 `render(t)` 逐帧确定性生成
（场景/道具/雨/光全部代码绘制；人物使用用户提供的四视图参考图作为透明底贴图），后期只做合轨与字幕。

| | |
|---|---|
| 成片 | `yuai-sketch.mp4`（H.264 高码率 + 原曲 AAC 流拷贝） |
| 时长 | 260.5 s（= 音频实测 260.504 s，6252 帧） |
| 画面 | 1920×1080 / 24 fps；钢笔墨线 + 透明淡彩；纸纹/水痕/雨雾/湿气/彩虹 |
| 声音 | 用户提供的《雨爱》原曲（未重编码；无旁白、无额外配乐） |
| 字幕 | 36 行歌词，手写体（马善政 Ma Shan Zheng + Caveat 混排），深灰墨色，底部居中逐行淡入；另附 `yuai-sketch.srt` |
| 水印 | 无 |
| 风格 | Lemo-Opuscar「Urban Sketch · Pen & Wash 钢笔淡彩」 |

## 怎么看

- 直接播放 `yuai-sketch.mp4`；海报 `poster.jpg`（第 3.6 s 的片名与窗边：雨爱 / 信 / 干花 / 远城）。
- 歌词时间轴：`data/lyrics.json`（36 行，逐句对齐实测演唱）；`data/audio-report.md` 是音频结构分析报告。
- 分镜/导演阐述：`TREATMENT.md`（含附录 A：为什么按音频重切段落边界）。
- 制作规范（给协作 agent 的 API 与美术规范）：`PRODUCTION.md`。

## 文件结构

```
yuai-sketch/
├─ index.html · main.js          # 页面：paperBase → Scene.draw → 调色/转场 → 纸纹/暗角 → 字幕
├─ src/
│  ├─ engine.js                  # 笔触/水彩/人物骨架/手写（Lemo-Opuscar urban-sketch 风格引擎的二次开发）
│  ├─ core.js                    # 相机与视差、纸张、Scene（分层的逐帧生长 + 渲染缓存烘焙）、速写构件、字幕
│  ├─ fx.js                      # 雨丝/玻璃水珠/雾气/呼吸白雾/灯光光晕/光斑/涟漪/水花
│  ├─ character.js               # 女生（浅色针织衫外搭薄外套、长发）、男生剪影、雨伞、手部特写
│  ├─ shots.js                   # 唯一时间源：11 个音频段落 × 40 个镜头（t0/dur）
│  ├─ sets/window.js             # 公寓窗景（墙/窗框/玻璃/窗帘/窗外城市/窗台旧物/片名）—— 全片核心景
│  ├─ sets/room.js · street.js · sky.js   # 室内 / 街巷 / 天空彩虹 三组布景
│  └─ scenes/lead-window.js · room.js · street.js · sky.js  # 40 个镜头，按组登记
├─ data/                         # lyrics.json / sections-detected.json / audio-report.md / audio-meta.json
├─ fonts/                        # 5 个 OFL 手写体（子集化、离线自托管）+ fonts.css
├─ assets/                       # song.m4a（原曲音轨，流拷贝）、song.wav（分析用）
├─ tools/                        # make_srt.py（歌词 → .srt）、audio/（音频分析与自检脚本）
└─ out/                          # 渲染中间物（video.mp4、评审静帧、接触表）
```

## 时间轴（唯一时间源：`src/shots.js`）

片段边界以音频实测为准（BPM≈80，4/4）：

| # | 段落 | 秒 | 镜头 |
|---|---|---|---|
| 1 | 前奏 | 0–16.29 | 1.1 / 1.2 |
| 2 | 主歌1（窗外的天气…学会放弃） | 16.29–50.94 | 2.1–2.5 |
| 3 | 副歌1（听雨的声音…Rainie Love） | 50.94–75.01 | 3.1–3.6 |
| 4 | 副歌1b（窗外的雨滴…彩虹的美丽） | 75.01–99.90 | 5.1–5.6 |
| 5 | 纯器乐间奏 | 99.90–124.32 | 4.1 / 4.2 |
| 6 | 桥段（冷冷的空气…一万颗雨滴的距离） | 124.32–146.30 | 4.3 / 4.4 |
| 7 | 主歌重复（离开你…学会放弃） | 146.30–161.95 | 6.1–6.4 |
| 8 | 副歌B（听雨的声音…） | 161.95–185.90 | 7.1–7.6 |
| 9 | 尾副歌（窗外的雨滴…彩虹的美丽） | 185.90–213.09 | 8.1–8.6 |
| 10 | 终段副歌（屋内的湿气…彩虹的美丽） | 213.09–236.20 | 9.1 / 9.2 |
| 11 | 尾奏 | 236.20–260.50 | 9.3 / 9.4 / 9.5 |

> 用户分镜表给的秒数与真实歌声段落偏差较大（副歌实际 50.94 s 才进、尾奏 236.20 s 才开始、
> 99.90–124.32 s 是纯器乐间奏），为满足"以音频实际长度为准 + 歌词按音频叠加"，
> 内容顺序不变、边界按实测重切。详见 `TREATMENT.md` 附录 A 与 `data/audio-report.md`。

## 第二版（v2）改了什么
- **v2.6 手部素材直用**：7.5「伸手接雨」的手部特写改为直接用用户提供的手部插画（透明底 `assets/char/hand.png`），
  只截取手指+手掌，袖口按原画风补一条袖子盖住下缘；其余近景手也优先用这张手。

- **v2.5 握伞对齐**：人物贴图改用"背面举手"那张时，从贴图像素里量出举起的手的位置，伞直接锚定在这只手上，
  杆子与手不再脱离；举伞镜头统一用举手姿态。

- **v2.4 整幅参考插画直用**：用户提供了完整的室内插画（`assets/char/room_scene.png`）。2.3 / 5.1 / 5.2 / 5.3 / 6.1 / 7.3
  这六个室内镜头改为直接在该插画上做缓慢推拉/横移（取景避开原图自带的字幕字迹），再叠纸色与字幕带；
  其余镜头保持代码绘制的水彩纸面风格。

- **v2.3 人物直接用参考图**：按用户提供的人物四视图（正面/3-4/侧面/背面/背面举手）做成透明底 PNG 贴图
  （`assets/char/`），站立与行走镜头直接使用；坐/跪两镜仍用简笔骨架画（因为要跟行李箱/信等道具对齐）。
  伞按参考图改为伞面在上、伞柄朝下；手部特写统一成简笔手（掌 + 圆头手指 + 拇指）。

- **v2.2 人物重构（简笔画）**：按用户建议，全片人物改用**简笔画**画法重画（见 `REFERENCE.md` 的公开比例参考）：
  头/发型/脸用最少笔画（点眼、短眉、一笔鼻、微笑），身体用单线 + 平涂淡彩，手改为"掌 + 圆头手指 + 拇指"的简笔手，
  伞改为伞面在上、伞柄朝下、手握伞杆的正确姿态；房间里的手部特写也统一成这套简笔手。

- **v2.1 修正**：头发不再垂到下巴/胸前（原来看起来像络腮胡）——改为"颅后发块 + 两侧落在肩前的长发"，
  前发只到眉毛上方；脸宽、眼型、眉位按正常人物比例微调。


- **人物脸部重做**：换掉原先"留白脸 + 一个点"的画法，新增 `src/head.js` 自绘头部系统——
  鹅蛋脸型、上睫毛线与小瞳仁、细眉、鼻尖一笔、柔软的嘴、极淡腮红；长发分后发块 / 斜刘海 /
  鬓发三层，带发丝高光与起风时的飘动。正脸、3/4、侧脸、背影四种视角自动切换；
  近景加细节、远景自动简笔（r<22px 只留最少笔画），保证小特写不"糊"。
- **身体比例修正**：肩宽 / 胸腔加宽，不再头大身薄。
- **画面更丰富（正片整体）**：
  - 全局后期：水彩泛光（低分辨率 screen 叠回）、细纸纹墨点、光里浮动的尘埃、
    暖光/冷角的光呼吸；纸张肌理与暗角加强，空白纸面不再"空"。
  - 窗边场景（`src/sets/window.js`）新增：墙上一幅小画框、一束挂着的干花、窗台玻璃瓶插干枝、
    折布 + 铅笔 + 一叠相纸、右侧暖灯的墙光池、窗光落在窗台上的一道亮——同时保留原来的
    信 / 行李箱 / 窗帘 / 水珠 / 雨雾。
  - 房间、街道、天空三组场景由协作者做了第二轮加料（照片墙、地毯、蜡烛、盆栽、旧鞋、
    湿地面反光、行道树、电线杆、两层天际线、玻璃水痕、彩虹光带、尘埃、窗台静物……），
    详见 `TREATMENT.md`。
